# 第10章 プロンプト集

本文に掲載しているプロンプトと同じものです。コピーして、Claude Codeの入力欄に貼り付けて使ってください。

各節の指示文は、本文の案内どおりに教材フォルダ（`10-1-daily-news`）を開いている前提で書かれています。

## 10-1　ルーティンでニュースを集める

教材フォルダ `10-1-daily-news` を開いて実行します。中に読ませるファイルはなく、`daily-news.md` と `today.html` を置く場所として使います（10-2も同じフォルダで進めます）。

ニュースを集めて記録する（手で1回実行）:

```text
生成AIに関する直近3日分のニュースをWebで調べて、daily-news.md に記録してください。

- 今日の日付を見出しにする
- 各ニュースについて、タイトル、URL、公開日、3行の概要を書く（概要は記事の文を写さず、要点を言い換える）
- 公開日が確認できない記事や、本文を取得できなかった記事は「未確認」として分ける

あわせて、今回書いた記事の中から上位5本を選び、新聞風のレイアウトの today.html を作ってください（毎回上書き）。
```

収集を毎朝の定期実行に乗せる（デスクトップアプリのCodeタブで `10-1-daily-news` を開き、Claudeに入力してルーティンを登録）:

```text
毎朝8時に、現在のフォルダで次の作業を実行するローカルルーティンとしてscheduled-tasksで登録してください。

生成AIに関するニュースのうち、前回の実行以降に公開されたものをWebで調べて、daily-news.md に追記してください。

- 実行日の実際の日付を見出しにする
- daily-news.md の末尾にある直近1週間分を読んで、すでに載せたURLや話題は再掲しない
- 各ニュースについて、タイトル、URL、公開日、3行の概要を書く（概要は記事の文を写さず、要点を言い換える）
- 公開日が確認できない記事や、本文を取得できなかった記事は「未確認」として分ける

あわせて、今回書いた記事の中から上位5本を選び、新聞風のレイアウトの today.html を作ってください（毎回上書き）。
```

## 10-2　会話履歴で収集の基準を作る

会話履歴から `interests.md` の下書きを作る（VS Codeで10-1と同じ `10-1-daily-news` を開いて実行）:

```text
~/.claude/projects/ の下にある会話履歴（JSONLファイル）から、
私が入力した発言だけをスクリプトで抽出してください。

その上で抽出した発言を分析し、次の3つを整理して、
このフォルダに interests.md の下書きを作ってください。

- 私が関心を持っていそうなテーマ
- 重視していそうな観点
- 興味がなさそうな話題

それぞれの項目に、そう推測した根拠になる私の発言を添えてください。
```

`interests.md` を読ませて1回実行する:

```text
interests.md を読んで、直近3日分の関連ニュースをWebで調べて、daily-news.md に追記してください。

- 今日の日付を見出しにする
- daily-news.md の末尾にある直近1週間分を読んで、すでに載せたURLや話題は再掲しない
- 各ニュースについて、タイトル、URL、公開日、3行の概要、interests.md のどの観点に関係するかを書く（概要は記事の文を写さず、要点を言い換える）
- 公開日が確認できない記事や、本文を取得できなかった記事は「未確認」として分ける

あわせて、今回書いた記事の中から上位5本を選び、新聞風のレイアウトの today.html を作ってください（毎回上書き）。
```

10-1で登録したルーティンの指示文も同じように変える。デスクトップアプリのサイドバーから「ルーティン」を開き、鉛筆アイコンで編集画面に入り、指示文の「生成AIに関するニュースのうち、前回の実行以降に公開されたものを」を「interests.md を読んで、前回の実行以降に公開された関連ニュースを」に書き換え、各ニュースの項目に「interests.md のどの観点に関係するか」を足す。
