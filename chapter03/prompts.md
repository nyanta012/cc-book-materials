# 第3章 プロンプト集

本文に掲載しているプロンプトと同じものです。コピーして、Codeタブのプロンプト欄に貼り付けて使ってください。

第3章では、Codeタブで `chapter03/practice/` フォルダを開いた状態で使う前提です。

## 3-2　過去の成果物に質問する

```text
@work-docs の中身をすべて読んで、直近3か月でどんな仕事をしてきたか整理してください。
特にA社案件の経緯と、3月のトラブル対応の現在の状況を教えてください。
それぞれ参照したファイル名も、ファイルパス付きで示してください。
```

## 3-3　新しい仕事の構成を相談する

新しいセッションを開いてから使います。

```text
来週の経営報告会議で、Q1（1〜3月）の振り返りを共有することになりました。まとめておいてください。
---
上記の依頼について @work-docs の過去資料を踏まえて、
どのような方向でまとめればよいでしょうか？
まだまとめは作らないでください。
```

## 3-4　構想をplan.mdに保存する

3-3で構成案を受け取った同じセッションで使います。

```text
あなたが出力した構成案をplan.mdというファイルに保存してください。
```

## 3-5　plan.mdからHTMLレポートを作る

新しいセッションを開いてから使います。

```text
@plan.md を踏まえて、経営報告会議向けのHTMLレポートを作ってください。
@work-docs の月次報告3本とトラブル対応報告を根拠にしてください。
データにない情報は書かないでください。
根拠が足りない情報には「要確認」と印を付けてください。
CSSはHTMLファイル内に含め、外部ファイルに依存しない1ファイルにしてください。
結果は executive_report_q1.html として保存してください。
```

A4横の印刷向けHTMLを作る（3-5「もう一歩進める：A4横でPDFにする」、新しいセッションで実行）:

```text
@plan.md と@work-docs の中身を根拠に、A4横での印刷を前提としたHTMLレポートを作ってください。
データにない情報は書かないでください。
根拠が足りない情報には「要確認」と印を付けてください。
余白、見出しのサイズ、改ページが整うようにしてください。
CSSはHTMLファイル内に含めてください。
結果は executive_report_q1_print.html として保存してください。
```
