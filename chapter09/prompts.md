# 第9章 プロンプト集

本文に掲載しているプロンプトと同じものです。コピーして、Claude Codeの入力欄に貼り付けて使ってください。

指示文は、本文の案内どおりに各節の教材フォルダ（`9-1-brand-slides`、`9-2-design-samples`、`9-3-expense-check`）を開いている前提で書かれています。`9-2-design-samples` は空のフォルダで、作った候補ファイルの置き場として使います。

## 9-1　見本の画像を渡して頼む

見本画像と内容メモを指定してスライドを作る（`9-1-brand-slides` フォルダを開いて実行）:

```text
@campaign-brief.md の内容をもとに、HTMLスライドを作成してください。

@sample-images/ に入っている既存スライド画像を見本にして、
配色、余白、見出しの大きさ、ロゴの置き方、部品の並べ方を近づけてください。

形式の条件は次の通りです。
- 外部ライブラリを読み込まない、1ファイルだけのHTML
- 16:9のスライドを1枚ずつ表示し、矢印キーで前後に送れる

内容は @campaign-brief.md から大きく変えず、
まずは発表に使える叩き台として deck.html を作成してください。
```

## 9-2　候補を作らせて選ぶ

フォントと配色を4案ずつ出させる（`9-2-design-samples` フォルダを開いて実行。「サイトは、…」の行は自分の題材に差し替えて使う）:

```text
design-picker.html という1ファイルのHTMLを作ってください。

- 見出し用・本文用の日本語フォントの組み合わせを4案、配色（背景・メイン・アクセント・文字色）を4案用意する
- フォントと配色をそれぞれボタンで選ぶと、同じ文面（サイト名・見出し・リード文・長めの本文）のプレビューに選んだ組み合わせがすぐ反映される
- フォント案にはフォント名、配色案にはHEXコード付きの色見本を書き添える
- 「この組み合わせの指定をコピー」ボタンを付け、押すと選択中のフォント名とHEXコードの一覧が指定文としてコピーされるようにする
- フォントも配色も、系統や雰囲気の違う4案にする
- フォントはGoogle Fontsから読み込んでよい

サイトは、AI活用の情報発信と開発支援をするにゃんたAIチャンネルのものです。
まだサイト本体は作らないでください。
合わせて、お勧めの組み合わせも理由付きで教えてください。
```

## 9-3　質問させて計画を確かめる

プランモードに切り替えてから、決めるべきことを質問させる（`9-3-expense-check` フォルダを開いて実行）:

```text
@expense-rules.md は、うちの会社の経費精算規程の抜粋です。
この規程に照らして、経費を申請する前に自分でチェックできるツールを作りたいです。
ブラウザで開ける1ファイルのHTMLにする予定です。

まだ要件が固まっていません。作り始める前に、
決めるべきことを、選択肢付きで私に質問してください。
```
