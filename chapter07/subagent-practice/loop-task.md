# 共有用お知らせ文の素材（全社員に配布）

来月から経費精算のシステムが新しくなります。
これを全社員に向けたお知らせ文にまとめて、
社内チャットやメールで配りたいです。
伝えたい要点は次の通りです。

- 切り替え日は6月1日（月）から。前のシステムは5月29日（金）の17時で停止する。
- 新しいシステムでは、領収書をスマートフォンのカメラで撮って添付できるようになる。
- ログイン方法は今までと同じ社内アカウントで、新しくパスワードを作る必要はない。
- 5月中に申請したぶんは、前のシステムで処理が完了する。またがる心配はしなくてよい。
- 操作に困ったら、情報システム部の問い合わせ窓口（内線1234）に連絡してほしい。

宛先は全社員。堅すぎず、でも要点が確実に伝わるトーンにしたいです。
