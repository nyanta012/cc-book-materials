# 共有用お知らせ文の素材（座席移動の案内）

再来月にオフィスのフロア構成が変わります。
これを社内向けのお知らせ文にまとめて、社内チャットで流したいです。
要点は次の通りです。

- 9月28日（月）から、営業部とカスタマーサポート部は7階から12階の新フロアに移る。
- 対象は営業部とカスタマーサポート部だけ。ほかの部署の座席は変わらない。
- 移る人は、9月25日（金）の17時までに私物を段ボールに詰めておく。段ボールは9月14日（月）から総務部で配る。
- 12階は固定席ではなく、チームごとのエリア内で好きな席を選ぶ方式に変わる。
- 電話番号と郵便物の宛先は変わらない。
- 質問は総務部の窓口（内線5678）へ。

宛先は全社員。堅すぎず、でも要点が確実に伝わるトーンにしたいです。
