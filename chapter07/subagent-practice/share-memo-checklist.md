# 社内お知らせ文チェックリスト

社内向けのお知らせ文（メール・社内チャットで全社員に配布するもの）をレビューする際のチェックリストです。5つの観点を、それぞれ「はい/いいえ」で判定できる項目に分解しています。すべて「はい」になることを目指してください。

## 正確性・整合性

- [ ] 日付・数値などの表記は文書内で統一されており、相対表現（「来月」「今週」など）と絶対日付が混在して矛盾を生んでいないか？
- [ ] 記載されているスケジュール・条件・手順などの情報同士に矛盾がないか？

## 網羅性

- [ ] 読み手が判断に迷いそうな例外ケースや境界（切り替え期間中の扱い、対象外になる条件など）に触れているか？
- [ ] 読み手が対応するために必要な情報（対象範囲・期限・問い合わせ先など）に抜け漏れがないか？

## わかりやすさ・構成

- [ ] 見出しや箇条書きを使い、一読で全体像を把握できる構成になっているか？
- [ ] 専門用語や社内特有の略語には、必要に応じて説明が添えられているか？

## トーン

- [ ] 全社員が読んでも堅苦しすぎず、かつ失礼にならない丁寧さで書かれているか？
- [ ] 読み手に不要な不安や負担を与える表現（過度な謝罪、曖昧な警告文句など）がないか？

## 行動喚起の明確さ

- [ ] 読み手が「いつまでに・何をすべきか」、または「何もしなくてよいか」を迷わず判断できるか？
- [ ] 次のアクション（問い合わせ先・申請方法など）への導線が明記されているか？
