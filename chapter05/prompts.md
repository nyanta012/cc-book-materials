# 第5章 プロンプト集

本文に掲載しているプロンプトと同じものです。コピーして、Claude Codeパネルの入力欄に貼り付けて使ってください。

第5章では、VS Codeの **File → Open Folder...** で `chapter05/meeting-notes/` フォルダを開いた状態で使う前提です。

## 5-2　`CLAUDE.md` の動作確認（ニャーテスト）

フォルダ直下に `CLAUDE.md` というファイルを作り、次の1行を書きます（これは入力欄ではなく、ファイルに書く内容です）。

```markdown
回答の最後に、必ず「ニャー」と一言だけ添えてください。
```

そのうえで、Claude Codeを起動して何か入力してみます。内容は何でも構いません。

```text
こんにちは
```

## 5-3　議事録を作る

```text
@raw/meeting_0501.txt を読んで、
社内共有用の議事録にまとめてください。
要約、決定事項、アクションアイテム、要確認事項に分けて、
担当者や期限が不明なものは要確認に入れてください。
```

## 5-3　Skillとして保存する

```text
今やった議事録作成の手順を、meeting-minutes という名前のSkillとして保存してください。
次回からは、会議メモのファイル名を渡すだけで、同じ形の議事録が作れるようにしたいです。
```

## 5-3　スラッシュコマンドで呼び出す

```text
/meeting-minutes @raw/meeting_0501.txt を議事録にしてください
```

## 5-4　Skillの修正を頼む

```text
meeting-minutes Skillを修正してください。
要約は3行以内に、アクションアイテムは表形式で出すようにしてほしいです。
```

## 5-4　修正後の動作確認

新しいセッションを開いてから実行してください。

```text
/meeting-minutes @raw/meeting_0501.txt を議事録にして、
minutes_0501.md というファイルに保存してください
```

## 5-5　プラグイン管理画面を開く

```text
/plugins
```

## 5-5　マーケットプレイスを追加する（Marketplacesタブの入力欄に入れる）

```text
anthropics/skills
```

## 5-5　プラグインを検索する（Pluginsタブの検索欄に入れる）

```text
document-skills
```

## 5-5　`document-skills` の動作確認

```text
@minutes_0501.md の議事録から
/document-skills:pdf を利用して、
決定事項とアクションアイテムを1枚のPDFとして書き出してください。
```
