# 第8章 プロンプト集

本文に掲載しているプロンプトと同じものです。コピーして、Claude Codeの入力欄に貼り付けて使ってください。

指示文は、本文の案内どおりに教材フォルダ（`8-1-survey`）を開いている前提で書かれています。8-3（スマホから頼むほかの方法の紹介）には、コピーする指示文はありません。

## 8-1　Remote Controlで続きを頼む

まずダッシュボードを作る（`8-1-survey` フォルダを開いて実行）:

```text
社内の経費精算システムについて取った利用者アンケートの回答が、
survey_2026.csv に入っています。
来週の改善会議で、どこから手を付けるかを決める材料にしたいので、
結果を一覧できる dashboard.html を作ってください。

1ファイルで開ける自己完結HTMLにしてください。
内容は次の構成にしてください。

- 回答件数
- 総合満足度の分布
- 利用頻度の分布
- 自由記述「操作で困った点」の主なテーマ
- 部署別の満足度
- 代表コメント

グラフや表のもとにした列名がわかるようにしてください。
```

スマホのClaudeアプリから、手元のClaude Codeに続きを頼む（`8-1-survey` フォルダを開いたまま `/remote-control` でつないだあと、スマホ側で送る）:

```text
ダッシュボードの部署別満足度のグラフを、満足度の高い部署から順に並べ替えてください。
```

## 8-2　アーティファクトで外から見る

ダッシュボードをアーティファクトとして発行する（8-1の会話の続きで、スマホからそのまま送る）:

```text
ダッシュボードをアーティファクトとして発行してください。
```

コラム「本格的なWebアプリを作りたくなったら」の依頼例（第5章の `anthropics/skills` マーケットプレイスから `example-skills` プラグインを導入している場合）:

```text
/example-skills:web-artifacts-builder を使って、
@dashboard.html を本格的なダッシュボードに作り直して、
アーティファクトとして発行してください。
```
