# 第6章 プロンプト集

本文に掲載しているプロンプトと同じものです。コピーして、Claude Codeパネルの入力欄に貼り付けて使ってください。

第6章では、VS Codeの **File → Open Folder...** で `chapter06/connector-practice/` フォルダを開いた状態で使う前提です。つなぐ先は皆さんの本物のGoogleアカウントなので、権限モードはManualに切り替えて進めます。また、Google DriveとGmailのコネクタを `claude.ai` のコネクタ画面で接続しておく必要があります（手順は本文6-3、6-4を参照してください）。

## 6-3　コネクタの確認と、文字起こしのDriveアップロード

コネクタが見えているかの確認は、次のスラッシュコマンドで行います。

```text
/mcp
```

疎通確認を兼ねて、文字起こしファイルをDriveにアップロードします。

```text
@meeting-transcript_2026-05-01.md を、
Google Driveに チーム議事録／2026-05／ フォルダを作成してから、そこにアップロードしてください。
Markdownのまま保存してください。
```

## 6-3　Drive上の文字起こしから議事録を作り、Driveに戻す

```text
Google Driveのチーム議事録／2026-05／meeting-transcript_2026-05-01.md を読んで、
社内共有用の議事録Markdownとして meeting-minutes_2026-05-01.md を生成してください。

構成は次の4つにしてください。
1. 要約
2. 決定事項
3. アクションアイテム
4. 要確認事項

担当者や期限が明確なものはアクションアイテムに入れ、
曖昧なものは要確認事項に入れてください。
```

できあがった議事録を、Drive上で読みやすい形式でDriveに戻します。

```text
@meeting-minutes_2026-05-01.md を、
Google Drive上で読みやすいようにGoogle Docs形式に変換して、
Google Driveの チーム議事録／2026-05／ フォルダに保存してください。
```

## 6-4　Gmailコネクタの疎通確認

```text
Gmailの最新のメール1件を取得して、内容を教えてください。
```

## 6-4　受信メールの読み込みから返信整理Markdownまで

```text
Gmailで前営業日以降に届いたメールを読み込んで、返信が必要なものだけを抽出してください。

各メールについて、次の5項目でMarkdownに整理してください。
1. 差出人
2. 件名
3. 返信が必要な理由（一言で）
4. 返信案の候補を2〜3つ
5. 期限の目安

社内告知、配信メール、自動返信メール、すでに返信済みのスレッドは除外してください。
期限が本文から読み取れない場合は、推測せず「記載なし」としてください。
結果は mail-triage_2026-05-15.md のように、今日の日付を入れたファイル名で保存してください。
返信文の送信やGmail下書きの作成はしないでください。
```

## 6-4　メール整理の流れをSkillにする

6-4の返信整理のやり取りをした同じセッションで依頼します。

```text
今やった前営業日以降のメール確認から、結果ファイルの保存までを、
morning-mail-triage という名前のSkillとして保存してください。

対象範囲は、Gmailで前営業日以降に届いたメールの確認、返信が必要なメールの抽出、
差出人・件名・返信が必要な理由・返信案の候補・期限のMarkdown整理、
今日の日付を入れたファイル名での保存までです。
返信文の送信やGmail下書きの作成は含めないでください。
```

次の日からの呼び出し方です。

```text
/morning-mail-triage
```
